# 位运算

## 常用技巧

```go
x & 1           // 判断奇偶（等价 x%2）
x & (x-1)       // 去掉最低位的 1（Brian Kernighan）
x | (x+1)       // 设置最低位的 0
x ^ x = 0       // 自身异或为 0
x ^ 0 = x       // 与 0 异或不变
n & (-n)         // 取最低位的 1（lowbit）
```

## 面试常问

- `n & (n-1)` 为什么能去掉最低位的 1？
- 如何不用额外变量交换两个数？（`a ^= b; b ^= a; a ^= b`）
- 如何快速判断一个数是 2 的幂？（`n > 0 && n & (n-1) == 0`）
