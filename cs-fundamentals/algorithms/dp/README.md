# 动态规划（Dynamic Programming）

## 解题框架

```
1. 定义状态：dp[i] 代表什么
2. 状态转移方程：dp[i] = f(dp[i-1], ...)
3. 初始条件：dp[0] = ?
4. 遍历顺序：从小到大 / 从大到小
5. 返回结果：dp[n] 或 max(dp[...])
```
