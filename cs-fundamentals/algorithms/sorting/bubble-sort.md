# 冒泡排序（Bubble Sort）

**标签**: #algorithm #sorting #基础
**难度**: ⭐
**时间复杂度**: 平均 O(n²) / 最好 O(n)（已有序时提前退出）/ 最坏 O(n²)
**空间复杂度**: O(1)
**稳定性**: ✅ 稳定

---

## 核心思想

重复遍历数组，比较相邻元素，如果顺序错误就交换。每一轮把当前未排序部分的最大值"冒泡"到末尾。

## 动画示意

```
初始: [64, 34, 25, 12, 22, 11, 90]

第1轮（最大值 90 冒到末尾）:
  [34, 25, 12, 22, 11, 64, | 90]

第2轮（次大值 64 到倒数第二位）:
  [25, 12, 22, 11, 34, | 64, 90]

第3轮:
  [12, 22, 11, 25, | 34, 64, 90]

...逐步缩小未排序区域
```

## Go 实现

```go
package main

import "fmt"

// bubbleSort 对整数切片进行升序冒泡排序。
// 核心思想：重复遍历数组，比较相邻元素，如果顺序错误就交换，
// 每一轮把当前未排序部分的最大值"冒泡"到末尾。
func bubbleSort(arr []int) {
    n := len(arr)

    // 外层循环：共需要 n-1 轮，每轮确定一个最大元素的最终位置
    for i := 0; i < n-1; i++ {
        // 标记本轮是否发生过交换
        swapped := false

        // 内层循环：比较相邻元素，范围随每轮缩小（末尾已排好）
        for j := 0; j < n-1-i; j++ {
            if arr[j] > arr[j+1] {
                // 相邻元素逆序，交换它们
                arr[j], arr[j+1] = arr[j+1], arr[j]
                swapped = true
            }
        }

        // 如果本轮没有发生任何交换，说明数组已经有序，提前退出
        if !swapped {
            break
        }
    }
}

func main() {
    data := []int{64, 34, 25, 12, 22, 11, 90}
    fmt.Println("排序前:", data)
    bubbleSort(data)
    fmt.Println("排序后:", data)
}
```

## PHP 实现

```php
<?php

function bubbleSort(array &$arr): void
{
    $n = count($arr);

    for ($i = 0; $i < $n - 1; $i++) {
        $swapped = false;

        for ($j = 0; $j < $n - 1 - $i; $j++) {
            if ($arr[$j] > $arr[$j + 1]) {
                [$arr[$j], $arr[$j + 1]] = [$arr[$j + 1], $arr[$j]];
                $swapped = true;
            }
        }

        if (!$swapped) {
            break;
        }
    }
}

$data = [64, 34, 25, 12, 22, 11, 90];
bubbleSort($data);
print_r($data);
```

## 优化点

| 优化 | 说明 |
|------|------|
| 提前退出 | 一轮无交换 → 已有序，break |
| 记录最后交换位置 | 下一轮内循环只需遍历到该位置 |
| 双向冒泡（鸡尾酒排序） | 同时从两端向中间冒泡，减少轮次 |

## 适用场景

- 教学演示（最容易理解的排序）
- 数据量极小（< 50）
- 几乎有序的数据（提前退出优化后接近 O(n)）
- **生产环境几乎不用**（性能太差）

## 面试追问

### Q1: 冒泡排序为什么是稳定的？

相等元素不交换（`arr[j] > arr[j+1]` 是严格大于），所以相同值的相对顺序不变。

### Q2: 最好情况为什么是 O(n)？

已有序时，第一轮遍历没有任何交换 → `swapped = false` → break。只遍历了一轮 = O(n)。

### Q3: 和选择排序的区别？

- 冒泡：相邻交换，稳定，可提前退出
- 选择：每轮选最小放到前面，不稳定，无法提前退出
- 都是 O(n²)，但冒泡的交换次数通常更多
