# _meta

项目元数据：模板、脚本、约定。用下划线前缀让它排在目录列表最前。

## 内容

- [templates/question.md](./templates/question.md) — 单题模板
- [templates/topic.md](./templates/topic.md) — 专题模板
- [scripts/](./scripts/) — 辅助脚本（生成索引、批量重命名等）

## 命名与格式约定

- 文件名：小写英文 + 连字符，例如 `slice-vs-array.md`
- 标签：`#语言` `#主题` `#难度` `#来源`，如 `#go #concurrency #高频 #bytedance`
- 难度：`⭐` 到 `⭐⭐⭐⭐⭐`
- 时间：面试实录用 `YYYY-MM-公司-岗位.md`
