# 面试实录

真实面试记录，按日期 + 公司 + 岗位命名，一场一份。

## 文件命名规范

```
YYYY-MM-公司-岗位[-轮次].md
```

示例：
- `2025-01-bytedance-backend-1.md`
- `2025-02-alibaba-p6.md`
- `2025-03-tencent-golang.md`

## 使用建议

1. 面试结束当天记录，趁记忆新鲜
2. 用 [_template.md](./_template.md) 模板
3. 具体题目沉淀到对应主题目录（`go/`、`php/`、`system-design/` 等）
4. 本目录只保留面试全流程回顾
