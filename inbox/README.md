# Inbox 收集夹

看到题、想到问题、刷到好文章，先扔进来，不用纠结分类。**定期清理归档**到对应主题目录。

## 使用方式

- 新建 `YYYY-MM-DD-简短描述.md`，随便写
- 或者一个大文件 `notes.md` 持续追加
- 关键：**低门槛、快速捕获**

## 归档节奏

- 每周日花 30 分钟整理，把 inbox 里的内容分散到主题目录
- 归档后从 inbox 删掉
- 保持 inbox 不超过 20 个文件

## 参考

- 类似 GTD（Getting Things Done）的 Inbox
- 类似 Zettelkasten 的临时笔记 → 永久笔记流程
