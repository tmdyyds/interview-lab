# 实战 Case

面试常见的系统设计题。每个 case 建议按：需求 → 估算 → 架构图 → 数据模型 → 关键流程 → 扩展点 → 权衡 的结构写。

## 计划收录

- **秒杀系统**：库存扣减、防超卖、限流、异步下单
- **短链服务**：ID 生成、301/302、缓存策略、防刷
- **IM 系统**：长连接、消息推送、离线消息、群聊
- **Feed 流**：推模式 vs 拉模式 vs 推拉结合
- **抢红包**：预分配、随机金额
- **分布式 KV 存储**：一致性哈希、副本、故障转移
- **点赞/评论系统**：高并发写、异步聚合
- **限流服务**
- **搜索服务**：ES + 数据同步
- **对象存储**（简化版 S3）
- **发号器服务**（雪花/号段）
- **登录注册系统**：密码加密、JWT、SSO、OAuth

## 面试常问模板

- 请设计一个 XX 系统
- 每秒 10w 请求怎么扛？
- 数据量 100 亿怎么存储？
- 如何保证高可用？
